# SGR-BENCH Evaluation Guidelines

This repository contains the implementation guidelines for SGR-BENCH evaluation.

## Repository Structure

- `eval/eval.md`: concrete implementation guidelines for the SGR-BENCH evaluation code

## Scope

This repository documents the evaluation-side specification of SGR-BENCH, including:

- evaluation scope and coverage boundaries
- final structured-output-centered scoring
- current limitations of trajectory-level evaluation
- usage boundaries of the benchmark as an evaluation and diagnosis resource
- construction-time bias considerations under LLM-assisted drafting

## Note

This is a guideline-oriented repository for SGR-BENCH evaluation implementation, rather than a full training corpus or a complete real-time web-search benchmark system.
